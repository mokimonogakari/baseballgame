|---|---|

## 1. 試合画面のレイアウト

### 1-1. カメラ（打撃時の視点）
- 打撃・投球画面は**捕手の後方やや上から投手を見下ろす視点**が標準（オプション名「ノーマル」）。打者は画面の左右どちらかに大きく立ち（右打者は画面左＝三塁側）、ストライクゾーンは画面中央の下寄りに描かれる。【観察: 2016 説明書 p.07 写真】
- オプションに「カメラ視点（打撃）」「カメラ視点（投球）」が別々にある。大会レギュレーションでは両方「ノーマル」指定。【公式: 国体 2020 レギュレーション、めっちゃeすぽっカップ ルール表】
- 2018 の対戦モード説明では、打撃視点は「キャッチャー」「バッター」、投球視点は「キャッチャー」「ピッチャー後方」があり、視点のサイズ（リアルサイズ等）も選べる。【公式: https://www.konami.com/pawa/2018/mode/game】
- 2018 で新カメラ「フカン（俯瞰）」を追加。テレビ中継でときどき見る高い視点で、**変化球の軌道が強調される**のが狙い。【開発: 前夜祭 試合編】
- 投手後方視点はストライクゾーンが小さく見えて投げにくい、という開発者の発言あり。【開発: 前夜祭 試合編】
- 2020 系では初期設定が「ダイナミック」で、ノーマルに戻す人が多かったという攻略記事あり。【攻略: https://andoroidou.hatenablog.com/entry/2020/08/13/124345】
- 投球開始前なら右スティック押し込みでカメラを切り替えられる（2018 Ver1.01〜、2022 も同様）。走塁時は変更不可、守備時は右スティックで回せる。【公式: 2018 FAQ No.63】【攻略: kamigame 2022】
- **本作への示唆**: 2D の本作では視点切替より「捕手後方ノーマル視点を 1 つ、きちんと見やすく」が正解。打者が大きく片側に立ち、ゾーンが中央下にある現状の構図はパワプロ標準と一致している。

### 1-2. 打撃画面の HUD 配置（2016 の写真を読み取り）【観察: 2016 説明書 p.07】
| 位置 | 内容 |
|---|---|
| 左上 | 小さな四角いスコア枠: 上段に「3回表」、左に両チームのロゴと得点（上=先攻）、右に B/S/O のランプ（B=緑、S=黄、O=赤の丸）と走者のひし形 |
| 上中央 | **球種ガイド**（投手の持ち球を十字・放射状の矢印で表示。中央の丸＝ストレート、矢印の先の数字＝変化量） |
| 右上 | 風向き（矢印）と風の強さ（数字 m） |
| 右中段 | **走者の様子**のワイプ（一塁走者を小窓で映し、名前を表示） |
| 左下（上段） | 投手の「発動中の特殊能力」チップ列（緑・青・赤の色付き）と守備シフト表示 |
| 左下（中段） | **投手プレート**: 「P」、名前、調子の顔マーク、先発/リリーフ印、防御率、奪三振、スタミナバー |
| 左下（下段） | 打者側の能力チップ列（「強振」表示はカーソルが強振のときだけ出る）と**打者プレート**: 打順、名前、調子マーク、守備位置、打率・本塁打・打点 |
| 中央下 | 細いピンクの線のストライクゾーン（縦長の長方形）、黄色のミートカーソル |

- 投手・打者の情報は**左下に縦に積む**配置で、画面の中央〜右はボールと打者のために空けている。プレートの地色で適性（先発=赤、リリーフ=桃、捕手=水色、内野=黄、外野=黄緑など）を示す。調子は顔マークの色 5 段階（良い順に 桃→赤→黄→青→紫 系）。【観察: 2016 説明書 p.07】
- 試合設定に「**投打情報表示**（能力）」「**走者情報表示**（選手名＋能力）」「**発動特殊能力表示**」があり、プレートに出す内容を切り替えられる。【公式: 国体 2020 レギュレーション、ルール表】
- 投球後、画面右下に**球種名と球速**（例: 「○○ 121km」形式）の小さなテロップが出る。【観察: 2016 説明書 p.04 の 3 枚目の写真】 WBSC 版の写真では画面右端に球速（145）と「弾道」のチップ。【観察: WBSC プレイガイド p.3】
- 守備・走塁画面: 画面外の選手の位置（端の矢印）、操作選手の頭上に▼、打球の落下点、右下に小さなダイヤモンド（走者位置）と風、アウトカウント。【公式: 2016 説明書 p.07】
- 能力画面（試合外）は「弾道・ミート・パワー・走力・肩力・守備力・捕球」の 7 行を「ラベル＋ランク文字（色付き）＋数値」で並べ、右に特殊能力を 4 列のグリッド（金=橙地、青=水色地、赤=赤地、効果なしの D 段階は薄く）で並べる。投手は球速 km/h・コントロール・スタミナと、変化球を放射状の矢印＋ブロックの長さで描く。【観察: WBSC プレイガイド p.11】

### 1-3. ストライクゾーンとカーソルの形【観察: WBSC プレイガイド p.4〜5 の図】
- ゾーンは**細いピンク（マゼンタ）の 1px 程度の枠のみ**で、9 分割の線は描かない。縦横比はおよそ 3:4（縦長）。
- オプション「ストライクゾーン」で表示/非表示を切り替えられる（大会は「表示する」）。【公式: レギュレーション】
- ミートカーソル（ミート打ち）は**横長の黄色い楕円**（縦横比およそ 1:2.3）。中心に小さな菱形、楕円を横切る白/黒の水平線（バットの軸）が楕円の外まで伸び、短い縦線が十字を作る。幅はゾーン幅の 6 割前後（ミート能力で変化）。
- 強振カーソルは**ゾーン幅の 1〜2 割ほどの小さな円**＋十字。
- 着弾点のマーカーは小さな白い四角／菱形。カーソルの水平線より**上で捉えるとフライ、下だとゴロ**の図示がある（既出）。
- 2016 説明書の写真では、カーソルが「強振」の時に左下に「強振」チップが点灯し、ミート打ちとの区別をプレイヤーに常時見せている。

### 1-4. テロップ類
- 打席ごとの選手紹介は「ウグイス嬢（場内アナウンス）」が担当し、球場によっては男性 DJ が担当（実際の球場に合わせる）。2024 以降の DJ も別の声優。【Wikipedia: パワフルプロ野球シリーズ（音声出演）】
- 試合設定に「**クローズアップ**」（大会では「なし」）、「**特殊能力演出**」「**ホームラン演出**」「**擬音演出**」「**守備ズームカメラ**」「**リプレイ**」「**観客数**」「**観客比率**（ホーム多め等）」「**顔モデル**（選手／パワプロ）」がある。＝ パワプロは演出のほぼ全部を個別に ON/OFF できる設計。【公式: レギュレーション、ルール表、Switch FAQ No.8】
- 「クローズアップ」「守備ズームカメラ」「擬音演出」の具体的な見え方は **未確認**（名前から、前者は投球間の選手アップ、守備ズームは打球処理時の寄り、擬音演出は打撃音の文字表示と推測）。

## 2. 打撃の詳細

前回のメモ（カーソルの基本、ミート/強振、真芯、タイミングと方向、弾道）に加え、**操作感**に関わる部分を掘り下げる。

### 2-1. カーソル移動の方式と速度
- 移動方式は「アナログ」と「デジタル」の 2 種。【公式: Switch FAQ No.14、2018 FAQ No.52】
  - **アナログ（既定）**: スティックの**傾きの向きと量がそのまま、ゾーン中心からのカーソル位置になる**（絶対位置指定）。端から端へ一瞬で動ける。【攻略: https://note.com/zerokagehb/n/n321c442a31f3（パワポケR の解説だが同エンジン系）】
  - **デジタル**: 方向キーの向きへ一定速度で動く（相対移動）。速度はオプション「**デジタルスピード**」で変更可。【公式: レギュレーション（項目名）】
  - デジタル時はボタン（2016 では SELECT または L2 短押し）で**カーソルを中心に戻せる**。【公式: 2016 説明書 p.04】
- 上級者・プロ選手はほぼアナログ。デジタルは微調整しやすいが、速いストレートの四隅や急に落ちる球に**間に合わない**のが弱点、という評価が一般的。デジタル設定でスティック入力する「アナデジ」という使い方もある。【攻略: https://sugarsnowcafe.com/pawapuro-degital-analog/ 、https://www.pawasuq.com/kihon/dateku/sousa.htm】
- アナログはスティックの遊びでカーソルが**震える**問題があり、「ボールを最後まで見てカーソルを止める」意識が勧められている。【攻略: https://shitasu.generalist-pt.com/pawapuro2020-batting/ 、https://hamatti-games.com/ppuroei-casol-hurue/】
- スマホ版は「ミートカーソル速度」をタイム→試合設定で変えられる（相対移動の倍率）。目安 40 前後という攻略記事あり。【公式: アプリヘルプ detail01】【攻略: ゲームウィズ（検索結果の要約）】
- 慣性（加減速）の有無・速度の具体値は **未確認**。
- 上級者は**変化を追ってカーソルを動かすのではなく、回転で球種を読んで着弾点に先回りして止めて待つ**。空振り・見送り後もカーソルを着弾点付近に残し、待つ間は小刻みに動かす。【メディア: inside-games 2020 https://www.inside-games.jp/article/2020/08/31/129390.html】

### 2-2. 着弾点・予測表示（難易度・オプション別）
- 投手が投げると着弾点（ボールがホームベース上を通過する位置）が表示され、そこにカーソルの中心を合わせる、が基本説明。【公式: 2016 説明書 p.04】
- オプション「**投球カーソル**」（表示しない／カーソル・変化点 など）と「**球種ガイド**」（方向／方向・球種 など）がある。大会設定は「投球カーソル: 表示しない」「球種ガイド: 方向」。【公式: レギュレーション】【攻略: https://tell7171-pawa.hatenadiary.com/entry/2023/02/12/213647】
- 「**フェード**（予測サークル）」系表示: リリース前におおよその到達位置を円で出し、ストレートなら円の中心に着弾点が出る。変化球は円の中心から着弾点がずれる方向で球種が分かる（横＝スライダー/シュート系、斜め＝カーブ/シンカー系、下＝フォーク系）。初期設定や「ノーマル」難度のサクセスでは ON、プロリーグでは OFF。【メディア: inside-games 2020】【攻略: https://www.marinarena84.com/pawapurobattingkottsu/】
- フェードなしでは**リリース後に着弾点が出る**ため、速い球は反応が間に合いにくい（特に引っ張り）。【攻略: marinarena84】
- フェードの代わりに「捕手のミット」位置で予測させる表示もある。【メディア: inside-games 2020】
- 投手がナイスピッチを出すと着弾点の表示が遅れる（既出、WBSC p.12）。
- 最速の球ではボールが見えてから十数フレーム（1/60 秒単位）しか猶予がない。【メディア: inside-games 2020】

### 2-4. 芯の判定・打球の強さ・音
- 打球の強さは 真芯 ＞ 芯 ＞ その他 の 3 段階。強振の図では真芯と芯に**別々の擬音**が添えられ、打撃音そのものを変えて当たりの質を耳で伝える設計。【公式: WBSC プレイガイド p.4（図）】
- カーソルの上部で捉えるとフライ、下部はゴロ、下端ギリギリは高いバウンドのゴロ、バットの根元・先端（カーソルの左右端）は弱い打球でバットが折れやすい。【攻略: pawasuq batiti】
- 真芯で捉えると実況が特別な掛け声を入れる。【Wikipedia】
- 2018 の開発談: 全力ストレートはナイスピッチでない限り「はっきりしたストライク」か「はっきりしたボール」になりやすいよう変更。COM 打者は大きく曲がる変化球（特にストライクからボールになる球）を打ち損じやすくした。調子は COM 打者のミート・パワーだけでなく**精度**にも影響する。【開発: 前夜祭 試合編】

### 2-5. タイミングと打球方向・流し打ち

- 流しはカーソル右上（右打者）、引っ張りは左上で捉えると方向が揃いやすい、ずらしすぎると凡フライ、という攻略。【攻略: https://pawapuro-app.hatenablog.com/entry/2017/06/29/120916】

## 3. オート（CPU 任せ）とテンポ

### 3-1. 何をオートにできるか
- オプションに「打撃操作」「走塁操作」「投球操作」「守備操作」「選手交代」をそれぞれ**マニュアル／オート**で選ぶ項目がある（大会は全マニュアル）。＝ **「打撃だけ自分、投球と守備は CPU」はパワプロでも正式な遊び方**。【公式: レギュレーション、ルール表】
- 試合前の「**出番設定**」で「チームに注目」を「する」にすると、特定の状況だけプレイできる（攻撃だけ・守備だけ）。【公式: Switch FAQ No.26、2018 FAQ No.64】
- 古くから「打撃と投球以外をオート」設定がある。【攻略: inside-games 2016（前回メモ）】
- 投球操作オートでは、ナイスピッチ率が投球レベル設定に関係なく固定で低めになり、COM 操作より不利という検証（30 試合×8 条件、600 試合超）。打球レベル・球速レベルでバランスを取る試み。【攻略: https://note.com/bito_orgteams/n/n7523aab8764b】 → **本作の CPU 自動投球は「ユーザー側が損をしない」強さに合わせるべき**、という教訓。

### 3-2. 試合の進め方の種類
- ペナントの試合進行: **通常試合**（全部操作）／**観戦試合**／**なりきりプレイ**（1 人だけ操作）／**監督試合**（指示のみ）／**スキップ**（結果だけ）／**高速試合**（早送り）。【公式: 2016 説明書 p.09】
- 2018 の開発談: 高速試合でも球場の影が動く様子が分かる（＝高速試合は**映像を早回しで見せる**方式）。【開発: 前夜祭 試合編】
- 2024-2025 の栄冠ナインには「試合スキップ」はなく、**高速試合とオートセーブ**がある（PV の誤表記を公式が訂正）。【公式: https://www.konami.com/pawa/2024-2025/topic/20240618】
- 2020 のペナントに「オート試合の投打バランスを 5 段階で設定」。【公式: https://www.konami.com/pawa/2020/powerful】
- 2016 の監督試合: 制限時間内に指示コマンドを選ばない／「おまかせ」で選手が自動行動。指示コマンドを使うとゲージが溜まり「一発コマンド」が使える。【公式: 2016 説明書 p.07】

### 3-3. スキップ・早送り
- 試合設定「**投球間隔**」があり、大会では「**スキップ禁止**」。＝ 通常は**投球と投球の間（投手が構え直す、捕手の返球など）をボタンで飛ばせる**。【公式: レギュレーション】
- ファミスタとパワプロはどちらも**捕手から投手への返球を省略**してテンポを保っている。パワプロは空振りでよろける・野手がベンチへ戻るなどの演出が多いが、**ボタンで一部を飛ばせる**。【メディア: https://victorysportsnews.com/articles/3154】
- アプリでは「試合中のさまざまな場面で早送りできる」「試合は自動で進み、大事な場面だけ操作する」。早送りはスタジアムの自操作時のみ試合終了まで可、という記事もある。【メディア: ファミ通 2014 https://www.famitsu.com/news/201412/26068754.html】【公式: https://www.konami.com/pawa/app/guide.html】

### 3-4. 1 試合の所要時間
- SFC『パワプロ2』の 1 試合（5-1、計 21 安打）は **23 分**。ファミスタは「1 試合 30 分の原則」で、1 人プレイ 18〜20 分。【メディア: victorysportsnews】
- 公式大会は 5 回制（国体 2020）や 6 回制（プロリーグ 2018）。＝ 対人の本気試合は短縮イニングが標準。【公式: 国体 2020 レギュレーション】【メディア: マイナビ 2018】
- 現行作の 9 回フル操作の所要時間は **未確認**（筆者推定 30〜60 分）。
- **本作への示唆**: ユーザーは攻撃しか操作しないので、9 回で **15〜20 分**、3 回で 5〜7 分を目標にできる。守備の半イニングは 1 分以内に収めたい。

### 3-5. スマホ版の「操作範囲」プリセット（打撃だけ操作の参考）
- サクセスの試合操作 6 種: **サクッと**（育成選手の打席だけ／投手ならピンチだけ）、ちゃっかりチャンス、しっかりピンチャン（チャンス・ピンチ・9 回を操作）、がっつり 8 回以降、ちょっぴり 9 回以降、COM におまかせ。チャンス＝味方走者が二塁以降、ピンチ＝相手走者が二塁以降。【攻略: ゲームウィズ https://xn--odkm0eg.gamewith.jp/article/show/148352（検索要約）】
- → 「打席だけ操作して、それ以外はおまかせで素早く進む」は人気の遊び方として確立している。本作の方針（打撃のみ操作）と一致。

## 5. サウンド・BGM・UI の見た目

- **球速レベル**は 5 段階で投球の体感速度を変える（初心者は遅めでタイミングを覚える）。**打球レベル**は打球の飛び方（「あまり飛ばない」等）。【攻略: bito 検証 note、YouTube 検証動画の題名】
- **COM の強さ**: よわい／ふつう／つよい／めちゃつよ／パワフル などの固定段階のほか、成績で変動する段階（イージー〜エキスパート）もあるとされる。打撃・投手・守備で別々に COM レベルを設定する遊び方が知られる（例: 打撃よわい・投手つよい・守備ふつう）。【攻略: 知恵袋 q11321782031, q13302650493】 各段階の内部数値は **未確認**。

## 7. スマホ・タッチ操作

| 作品 | 打撃のタッチ操作 | 工夫 |
|---|---|---|
| パワプロアプリ（ミート） | 画面に触れたまま指をスライドしてカーソルを動かし、**指を離すとスイング** | カーソル速度を試合中に調整（タイム→試合設定）【公式: ヘルプ detail01】 |
| パワプロアプリ（フルダケ） | 触れたまま待ち、ゾーンに来た球で指を離す。**黄色のゾーン**に来たら振る、**橙のゾーン**で打つとヒット確率が高い | 強振・バントを選ぶと自動解除。ON/OFF はタイム→試合設定【公式: ヘルプ detail06】 |
| パワプロアプリ（強振・バント） | 「強振」ボタンでモード固定、「強振やめる」で解除。「バント」ボタン→画面タップで構え→上下左右で調整→指を離すと構えをやめる | モードは**トグルで保持**（毎球押さなくてよい）【公式: ヘルプ detail02】 |
| パワプロアプリ（投球） | 球種をタップ→スライドでコース→離すと**タイミングバー**が動き、タップで止める。右ほど良い球、白（ナイスピッチ）は特定条件で出現、赤は危険 | 投球の質を 1 本のバーに集約【公式: ヘルプ detail03/04】 |
| プロスピA（ゾーン打ち） | 球が手元に来たらタップするだけ（初心者向け、対人では不可） | 打撃モードを「ゾーン打ち＆強振」、初期モードを強振に固定する設定がある【攻略: game8 https://game8.jp/prospi_a/635716】 |
| プロスピA（ミート/強振） | ミートサークルを指でスライド→離してスイング | **打撃カーソル移動速度**（初期値では追いつかない、4〜5 推奨）、**カーソル色**（緑が見やすい）、**打撃時のバット半透明化**、カメラ距離固定、守備・走塁「高速」設定【攻略: game8 635716】 |
| プロスピA（バント） | 長押しで構え、離すと見送り、上下左右で調整 | 【攻略: https://game8.jp/prospi_a/36282】 |

- 共通点: **「スライドで狙う → 離して振る」**が主流。タップの瞬間ではなく**離す瞬間**をスイングにすると、狙い（ドラッグ）とタイミング（リリース）が 1 本の指で自然に分かれる。
- カーソルが指で隠れる問題は一般的な課題（研究でも画面下の半透明パッドでカーソルを動かす手法が提案されている）。【研究: https://hosobe.cis.k.hosei.ac.jp/lab/wp-content/uploads/2023/03/r_nakamura-abstract.pdf（検索要約）】
- 本作は現在「ドラッグで相対移動＋ゾーンのタップでスイング」。タップ位置にカーソルが飛ぶので、**指の下にカーソルが隠れる**・**タップの瞬間に位置とタイミングを同時に決める必要がある**点で、アプリ方式より難しい。

## 9. 実装バックログ（試合体験）

前提（ユーザー決定）: **ユーザーは打撃のみ操作**、守備時は **CPU が自動で投げ**、守備も**自動で別画面（追う画面）なし**、試合は**すぐ始まる**（相手選びなし）、**ミートカーソルは動かせる**。すべて独自の名称・音・絵・文で作る。並びは「楽しさ・手触りへの効き目」の大きい順。

### P1（手触りと気持ちよさの核）

1. **カーソル移動の加速カーブと速度設定**
   いまは等速 3 セル/秒なので、中心から隅（約 1.4 セル）まで 0.47 秒かかり、normal の到達 700ms ではほぼ間に合わない。押し始め 0〜80ms は 2 セル/秒（微調整）、その後 150ms で最高 6 セル/秒まで加速、離したら即停止（慣性なし。パワプロのデジタル同様、止めたい所で止まるのが大事）。設定「カーソルの速さ 1〜5」を追加。中心に戻すキー（例: Shift／C 長押し以外のキー）も追加。
   → `js/game.js` の `loop()`（押し始め時刻を `held` に保持して速度を計算）、`CURSOR_SPEED` を表に置き換え。`js/main.js` の `DEFAULTS` に `cursorSpeed`、`js/screens.js` の設定項目。テストは不要（UI）。

2. **球速で到達時間を決める（体感速度）**
   到達時間 = 基準 ×（140 / 球速 km/h）^1 程度、変化球は球種の速度係数（カーブ 0.78 など）を掛ける。難易度は「基準時間（easy 1000 / normal 760 / hard 620ms @140km/h）」に変える。投手ごとの速さの違いが打席で体感できるようになり、緩急で打ち取られる面白さが出る。ナイスピッチ相当の CPU 投球は着弾点表示を少し遅らせる。
   → `js/game.js` の `startFlight`（`ms = diff.flight` を関数化）、`DIFFICULTY`。球速は `engine.getPitcher(state).pitching.velocity`、球種係数は `data.js PITCH_TYPES` に `speed` を追加。

3. **投手の投球モーションと一定のリリース予告**
   いまはボールが突然出る。CPU 投手のセット→足を上げる→腕を振る（合計 600〜800ms、毎回同じ長さ）を `chibi-pitcher` に付け、リリースの瞬間に球を出す。打者が「いち、にの、さん」でタイミングを取れる。足を上げた時点で着弾予測（フェード）を出す設定も可能にする。
   → `js/game.js` の `startCpuPitch`（`startFlight` をモーション後に遅らせる）、`css/style.css` に投手のキーフレーム。

4. **打球後の「自動守備ビュー（観る専用）」**
   追う画面を出さない代わりに、打球を**見せる**画面が必要。`fielding.js` を `userControlled:false` の観戦専用で使い、時間倍率 1.6〜2 倍、タップ／Z でその打球の結果まで即スキップ。ゴロは 1.2 秒、外野フライは 2 秒程度を上限に。俯瞰の小さなフィールド＋落下点マーカー＋走者のひし形を見せ、結果テロップで締める。単打で終わる平凡な打球は「見せない」設定（結果テロップだけ）も用意。
   → `js/game.js` の `openFieldView`（`userControlled` を常に false、`timeScale` と `onSkip` を渡す）、`js/fielding.js` に時間倍率とスキップ（`autoField` の結果へジャンプ）を追加。

5. **当たりの質で音・擬音・ヒットストップを変える**
   `event.contactTier`（shin2 / shin / other）ごとに打撃音を 3 種に分け、真芯は 70ms のヒットストップ（全アニメ停止）＋白フラッシュ＋独自の擬音テロップ（例: 「ドカッ！」系の独自語。パワプロの擬音は使わない）、芯は短い擬音、その他は鈍い音のみ。設定「擬音テロップ ON/OFF」。
   → `js/sound.js` に `hit_core / hit_good / hit_weak`、`js/game.js` の `contactFx` と `feedback`、`css/style.css`。

6. **ホームラン演出（確信歩き・打球を追う・飛距離テロップ）**
   本塁打確定時: 打者がバットを放る（フォロースルー＋バットが回転して落ちる）→画面が打球を追ってスタンドへパン（背景を上方向に 300px スクロール）→歓声が大きく→「ホームラン」＋飛距離 m・打球速度 km/h・角度のテロップ（プロスピのトラッキング風、数値は `ball.exitSpeed` `ball.launchDeg` `ball.landing` から）。全体 2.5〜3 秒、タップでスキップ。設定「ホームラン演出 ON/OFF」。
   → `js/game.js` の `animateBattedBall`／`applyResult`（hr 分岐）、`batterHTML` にバット投げのキーフレーム、`css/style.css`、`js/sound.js`（大歓声）。

7. **実況を状況別の文テンプレートに（`js/commentary.js` 新設）**
   タイミングを 4 つに分ける: ①打席登場（打順・名前・今日の成績・得点圏なら一言）、②投球前（カウントや点差に応じて 3 球に 1 回程度）、③打球直後（打球の種類・方向・当たりの質）、④結果後（得点、連続三振、猛打賞、逆転、サヨナラ）。同じ文が続かないよう直近 5 件を避ける。文はすべてオリジナル。将来の音声化に備え、文を「短い部品」の組み合わせで作る（名前＋定型）。
   → 新規 `js/commentary.js`（純粋関数 `comment(prevState, event, state, rng) → string|null`）、`js/game.js` の `tickerText` 設定箇所、`tests/` に重複回避のテスト。

8. **守備イニングのテンポ段階（通常／速い／打席まとめ）**
   ユーザーは守備で何もしないので、半イニングを 1 分以内に。設定「守備の進み方」: 通常（1 球 1.4 秒）、速い（1 球 0.6 秒・球の軌道だけ）、まとめ（打席ごとに結果だけ 0.8 秒表示）。どれでも Z/タップで次へ。守備中のチャンス・ピンチ（相手走者が二塁以降）では自動的に「通常」に戻して緊張感を残す。
   → `js/game.js` の `scheduleAutoPitch`/`cpuThrow`（`AUTO_PITCH_MS` を設定値に）、まとめ用に `engine.pitchContact`→`resolveBattedBall(autoField)` を打席終了までループする関数、`js/main.js`/`js/screens.js` の設定。

9. **打者・投手プレートを放送風に（左下に積む配置）**
   打席ごとに打者プレート（打順・名前・守備位置・調子・打率/本塁打/打点）を 1.2 秒大きく出してから定位置へ縮める。投手プレートは防御率・奪三振・スタミナ。投球後に右下へ「球種 球速km/h」テロップを 1 秒。
   → `js/game.js` の `template()`／`render()`（`panel-left/right` の情報を整理）、`css/style.css`。

10. **チャンス演出と応援曲**
    自チームの攻撃中は独自の応援メロディ（チームごと 2 曲を `music.js` の譜面で）を流し、得点圏に走者が出たら「チャンス」テロップ（0.8 秒）＋チャンス用の曲へ切り替え。出塁時は短いファンファーレ。
    → `js/music.js` に `cheer_red`/`cheer_blue`/`chance` トラック、`js/game.js` の `afterResult`/`enterReady` で切り替え（`ctx.music.play(name)` を追加）。

### P2（試合の厚み）

11. **予測表示の 3 方式（設定）**: 「予測円（リリース前におおよその位置の円）」「着弾点のみ（リリース後）」「なし」。予測円は狙い位置（`aimOf(pitch)`）を中心に、制球のばらつき（`controlSpread()` の考え方）を半径に。難易度とは独立。→ `js/game.js` の `startFlight`（ghost 処理の一般化）、設定。

12. **打撃アシスト（吸い付き 0〜3）**: カーソルを着弾点へ毎フレーム `k×dt` で寄せる（k = 0, 2, 4, 7 /秒）。かんたんの既定は 2。タッチ端末の既定も 2。→ `js/game.js` の `loop()`（`flight.finalLoc` に向けて補間）、設定。

13. **タッチの「スライド→離してスイング」方式（設定で選択）**: 指を置いた位置ではなく**相対移動**でカーソルを動かし、指を離した瞬間をスイング時刻にする（アプリ方式）。指の位置とカーソルが重ならないので隠れない。既存の「タップでスイング」は残し、設定で切り替え。強振・バントのモードはトグル保持（既に一部実装）。→ `js/touch.js`（pointerup をスイングに）、`js/game.js` の `touchZoneDown/touchZoneTap`、`dragCursor`。

14. **ゾーンとカーソルの見た目をパワプロ系の読みやすさに（ただし独自デザイン）**: ゾーンを縦長（幅 200×高さ 260 程度）にし、9 分割線は薄く／OFF 可。カーソルは横長（縦横比 1:2）＋バット軸の水平線を楕円の外まで伸ばし、上で当てるとフライ・下でゴロが直感的に分かるように。色は本作のアクセント（`--accent #FFD54A`）で独自に。→ `css/style.css`（`.zone` `.cursor`）、`js/game.js` の `locToPx`（縦横で別スケール）、`cursorSize` の ry 比。

15. **打者・投手の小さな仕草**: 空振り後によろける（120ms）、見逃し三振で首をかしげる、際どい見逃しで振り返る、死球でうずくまる、待機中にバットを小さく揺らす。→ `js/game.js` の `feedback`（`event.swing` と kind で分岐）、`css/style.css` のキーフレーム。

16. **リプレイ（自動・スロー）**: 長打・本塁打・併殺・サヨナラのあと、`ball.path` を 0.5 倍速で再生（「REPLAY」表示、タップでスキップ、設定で OFF）。→ `js/game.js`（`animateBattedBall` を path ベースにして再利用）、`js/fielding.js` の観戦ビューを再生専用で再利用。

17. **歓声のレイヤー化**: 常時の低い球場ノイズ＋打球が上がった瞬間の「おおっ」（打球の高さ・飛距離予測で音量）＋捕球での「ああ…」＋得点の大歓声。ホーム側が得点したら右寄り、ビジターは左寄りにパン（StereoPanner）。→ `js/sound.js` に `crowdLoop`/`crowdSwell(level, pan)`/`groan`、`js/game.js` の打球開始と結果時。

18. **特殊能力の発動フラッシュ**: エンジンが能力を使った打席・投球で、該当チップを 0.6 秒光らせ、パネル外に小さな帯（「◯◯ 発動」）を出す。設定「能力の演出 ON/OFF」。→ `js/engine.js` の event に `skillsUsed: [...]` を付ける（`skillOn` の呼び出しを記録）、`js/game.js` の `skillChips`/`render`。

19. **審判コールのタイミングと強弱**: 捕球音の 150〜250ms 後にコール。見逃し三振は大きく長いコール＋決めポーズ、ボールは小さく。フルカウントでは間を少し長く。→ `js/game.js` の `feedback`、`js/sound.js`（既存 VOICEVOX 素材の再生タイミングのみ）。

20. **場内アナウンス風の打者紹介（任意で音声）**: 打席前に「○番 ポジション 名前」をテロップ表示。音声は `speechSynthesis`（OFF 既定）。2 打席目以降は名前だけに短縮してテンポを守る。→ `js/game.js` の `enterReady`、`js/sound.js` に `announce(text)`。

21. **試合開始と終了の締め**: 開始は 1.5 秒の「プレイボール」（両チームのスタメンを 1 行ずつ流す）→即打席。終了は GAME SET → 決勝打を打った選手を優先する「きょうのヒーロー」カード（既存の MVP カードの選び方を「決勝点＞本塁打数＞安打」に）。→ `js/game.js` の `start`/`afterResult`、`js/engine.js` の `boxScore().mvp` の選定、`js/screens.js` の結果画面。

### P3（仕上げ・設定）

22. **演出の個別 ON/OFF 設定**: ホームラン演出、リプレイ、擬音テロップ、実況テキスト、能力演出、打者紹介。パワプロ同様「全部 OFF で最速」も可能に。→ `js/main.js` の `DEFAULTS`、`js/screens.js` の設定画面、各演出の分岐。

23. **難しさの分解（球の速さ・打球の飛び・CPU の強さ）**: いまの easy/normal/hard を残しつつ、詳細設定で「球の速さ 1〜5」「打球の飛び 1〜5」「相手投手の強さ 1〜5」を個別に。→ `js/game.js` の `DIFFICULTY`、`js/engine.js` の `TUNING` へ倍率を渡す。

24. **時間経過の背景表現**: イニングが進むと空の色をデー→夕方→ナイター（照明の光芒）へ、フェンスの広告やビジョンの表示を回ごとに切り替え。→ `css/background.css`（CSS 変数で空・影の色）、`js/game.js` で `data-inning` を付ける。

25. **選球の学習補助**: 見送った球の通過位置を 0.8 秒だけ小さな印で残し、ストライク/ボールが分かるようにする（かんたんのみ既定 ON）。→ `js/game.js` の `finishPitch`（`evLoc` に印）。

26. **所要時間の計測と目標**: 試合開始〜終了の実時間、守備半イニングの平均時間をデバッグ表示（`?debug`）で出し、9 回 15〜20 分・守備半イニング 60 秒以内を目標に各待ち時間（`RESULT_MS` `CHANGE_MS` `AUTO_PITCH_MS`）を調整。→ `js/game.js`、`js/main.js`。
