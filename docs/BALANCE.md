## 能力補正（重み乗算→正規化）

c=(contact-50)/49, p=(power-50)/49, v=(velocity-50)/49, k=(control-50)/49, d=readDifficulty-0.30

| 結果 | 乗数 |
| --- | --- |
| strike | exp(-0.65c + 0.35v + 0.25d) |
| foul | exp(0.15c) |
| single | exp(0.35c - 0.15p) |
| double | exp(0.35c + 0.35p) |
| triple | exp(0.35c + 0.15p) |
| hr | exp(0.35c + 0.85p) |

基礎確率 0 は補正後も 0。

## 投球位置

- aim = (zone.x-1, zone.y-1)、controlSigma = 0.45 - 0.20k
- 実際の位置 = aim + 球種の変化(dx,dy) + 正規乱数×controlSigma（x,y独立、rng注入）
- ストライクゾーン内: |x|<=1.5 && |y|<=1.5。見送り: ゾーン内=strike、外=ball
- ゾーン外スイング: strike×1.4、その他×0.7 して正規化

| 球種 | dx | dy | 見切り難度 |
| --- | --- | --- | --- |
| fastball | 0.00 | 0.00 | 0.15 |
| slider | 0.65 | 0.10 | 0.45 |
| curve | 0.40 | 0.65 | 0.55 |
| fork | 0.00 | 0.80 | 0.65 |
| sinker/shoot | -0.45 | 0.40 | 0.45 |
| changeup | -0.10 | 0.35 | 0.60 |

右投手基準。左投手は dx を反転。

## 手動プレイテスト項目

1. タイトル→試合→結果→再試合が進み、コンソールに例外が出ない
2. ステージ縮小時もクリック・タッチ位置と選択セルが一致
3. 距離判定が同セル0・隣接1・対角端2で、変化後の位置で判定
4. タイミング境界値（0, 0.3, 0.6, 1）が指定帯に入る
5. 確率表の各行合計100、補正後合計1、NaN なし
6. 見送り: ゾーン内ストライク／外ボール、安打やファウルにならない
7. ボール球スイングが ball にならない
8. 4ボール四球、3ストライク三振、2ストライク後ファウルで三振しない
9. meet は当てやすく power は空振り・本塁打が増える
10. contact/power を 1・50・99 にして傾向が変わる
11. velocity 上昇で空振り増、control 上昇でばらつき減
12. 球種の曲がり方向・量が描画と判定で一致、左投手は横だけ反転
13. 進塁・押し出し・本塁打の全員生還
14. 3アウト交代、9回裏スキップ、サヨナラ、同点処理、結果集計
15. `node tests/balance.mjs 200` で目標と比較し、一系統ずつ調整
