## 係数表

- 値は百分率（各行合計100）。スイング時の表なので ball は 0、strike は空振り。
- zoneDistance = max(|batX-pitchX|, |batY-pitchY|)（変化・制球誤差適用後のセル）。
- タイミング帯: |timing| 0–0.3 / 0.3–0.6 / 0.6–1.0。
- outcomeOrder: ball, strike, foul, groundout, flyout, single, double, triple, hr

## 能力補正（重み乗算→正規化）

c=(contact-50)/49, p=(power-50)/49, v=(velocity-50)/49, k=(control-50)/49, d=readDifficulty-0.30,
P=球威の優位 = w>0 ? w×(1−0.5×clamp(p,0,1)) : w（w=(実効球威-50)/49。docs/ENGINE-API.md 9 章）

| 結果 | 乗数 |
| --- | --- |
| strike | exp(-0.65c + 0.35v + 0.25d + 0.05P) |
| foul | exp(0.15c + 0.10P) |
| groundout | exp(0.10P) |
| flyout | exp(0.15P) |
| single | exp(0.20c - 0.15p - 0.12P) |
| double | exp(0.35c + 0.35p - 0.40P) |
| triple | exp(0.35c + 0.15p - 0.40P) |
| hr | exp(0.35c + 0.85p - 0.55P) |

（single の c 係数は draft-1 の 0.35 から 0.20 に調整済み。さらに `TUNING.*Base` の基礎重み倍率を掛ける。）

基礎確率 0 は補正後も 0。

## 投球位置

- aim = (zone.x-1, zone.y-1)、controlSigma = 0.45 - 0.20k
- 実際の位置 = aim + 球種の変化(dx,dy) + 正規乱数×controlSigma（x,y独立、rng注入）
- ストライクゾーン内: |x|<=1.5 && |y|<=1.5。見送り: ゾーン内=strike、外=ball
- ゾーン外スイング: strike×1.4、その他×0.7 して正規化

| 球種 | dx | dy | 見切り難度 |
| --- | --- | --- | --- |
| fastball | 0.00 | 0.00 | 0.15 |
| slider | 0.65 | 0.10 | 0.45 |
| curve | 0.40 | 0.65 | 0.55 |
| fork | 0.00 | 0.80 | 0.65 |
| sinker/shoot | -0.45 | 0.40 | 0.45 |
| changeup | -0.10 | 0.35 | 0.60 |

右投手基準。左投手は dx を反転。

### 当たりの質・タイミング（打球の形）の確認

`contactTier`（真芯/芯/芯以外）と早い/遅いスイングは、打席結果を決めた**あと**に打球の速さ・距離・種類だけを変える（docs/ENGINE-API.md 7.4.1）。
係数表と能力補正はそのままなので、上の表の差は乱数列が変わったことによるゆらぎの範囲。打球の構成と棄却サンプリングの不一致率は
`tests/balance.mjs` の最終行（HR・バントを除く打球）で確認する。

| 項目（800試合） | 導入前 | 導入後 | 変化 |

芯以外の安打を弱くすると CPU 守備でアウトになり不一致が 6.2% まで増え、安打が 15.8 に下がったので、安打は強い側にだけ寄せている（`qHitWeak 0`）。

### 球威の調整メモ

ロースターの実効球威の平均は 約 64（素の値 平均 61.4 ＋ 重い球 4 人、疲労で少し下がる）なので、P の平均は 約 +0.2。
そのままだと安打 15.5・打率 .232 まで下がったため、`singleBase / doubleBase / hrBase` をそれぞれ 約 ×1.06 / ×1.07 / ×1.11 に上げて相殺した。
詰まったゴロ（70〜105 km/h）は併殺になりにくく、55〜100 km/h では併殺 1.00 まで落ちたので 70〜105 に上げた。
球威の強さを変えるときは `power*` 係数と基礎重みをセットで動かす（平均の P が正なので、係数を強めると全体の打撃も下がる）。

## 手動プレイテスト項目

1. タイトル→試合→結果→再試合が進み、コンソールに例外が出ない
2. ステージ縮小時もクリック・タッチ位置と選択セルが一致
3. 距離判定が同セル0・隣接1・対角端2で、変化後の位置で判定
4. タイミング境界値（0, 0.3, 0.6, 1）が指定帯に入る
5. 確率表の各行合計100、補正後合計1、NaN なし
6. 見送り: ゾーン内ストライク／外ボール、安打やファウルにならない
7. ボール球スイングが ball にならない
8. 4ボール四球、3ストライク三振、2ストライク後ファウルで三振しない
9. meet は当てやすく power は空振り・本塁打が増える
10. contact/power を 1・50・99 にして傾向が変わる
11. velocity 上昇で空振り増、control 上昇でばらつき減
12. 球種の曲がり方向・量が描画と判定で一致、左投手は横だけ反転
13. 進塁・押し出し・本塁打の全員生還
14. 3アウト交代、9回裏スキップ、サヨナラ、同点処理、結果集計
15. `node tests/balance.mjs 200` で目標と比較し、一系統ずつ調整
