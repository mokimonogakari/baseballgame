# オマージュ選手一覧（ROSTER-HOMAGE）

4チーム76人の能力は、すべて**特定の実在のプロ野球選手（NPB/MLB の現役スター・OB）へのオマージュ**として設計しています。
データの本体は `js/data.js`、各選手の `model` がオマージュ元の説明です（下表の「オマージュ元」列と同じ文言）。

## 設計ルール

- **名前は意図的にすべて架空**です。肖像権・氏名権・パブリシティ権に配慮し、実名・愛称・本人を特定できる背番号・名前のもじりは使っていません。オマージュ元も「経歴・記録・プレースタイル」で表し、実名は書きません（このドキュメントも同様）。
- 能力値は本人の全盛期の成績と評判から換算しています（換算式は `js/data.js` 冒頭）。
  - 打率・安打 → ミート、本塁打・長打率 → パワー＆弾道、盗塁・走塁 → 走力、肩・補殺・盗塁阻止 → 肩力、守備指標・ゴールデングラブ → 守備力・捕球
  - 球速 → 球速（km/h）、与四球率 → コントロール、投球回・完投 → スタミナ、決め球 → 球種と変化量（伝説級の決め球は 6〜7）
- スケールはパワプロ準拠: 普通のレギュラーは C〜B（60〜79）、スターは A（80〜89）、**S（90+）は歴代屈指の選手の代名詞の能力だけ**。
  金特（天才打者・怪力・怪物球威）は歴代屈指の選手のみ、赤特は実際の弱点（三振の多い長距離砲 → 三振、制球難 → 四球）。
- 4チームの総合力はほぼ同じです。全員がスター級の“ドリームチーム”同士なので、能力はリーグ内の相対評価として代名詞以外を控えめにし、
  チームコスト（`playerCost` の合計）も 160〜167 にそろえています。CPU 同士の対戦（各カード 400 試合）でどの組み合わせも勝率 4〜6 割。
- 打順・投手陣の形（打順9人＝9番は先発投手、先発2・中継ぎ3・抑え1、控え野手5）と選手 id は従来どおりです（保存済みのマイチームもそのまま読めます）。

表の見方: 野手は「ミート/パワー/走力/肩力/守備力」、投手は「球速・コントロール・スタミナ・球種（変化量）」。ランク文字つき（例: A84）。
