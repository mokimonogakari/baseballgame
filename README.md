# ドキドキベースボール

パワプロ風のブラウザ野球ゲーム。ビルド不要の静的 HTML / CSS / JavaScript で、GitHub Pages で配信します。

- デザイン: https://claude.ai/artifact/6eSALzd4dFwWdR2sJDuwjq
- 仕様: [docs/SPEC.md](docs/SPEC.md)

## 遊び方

### スマホの短時間プレイ

「10球チャレンジ」は縦・横の両方に対応。黄色い輪にボールが来た瞬間に大きなスイングボタンを押します。ヒットの連続で加点、ホームランで演出と高得点。10球で終了し、自己ベストは端末内に保存されます。休けいボタンと、アプリを離れた際の自動停止に対応します。通常試合は横向きで遊び、未設定時の初期値は3回制です（保存済み設定は維持）。

| 操作 | キー | タッチ |
| --- | --- | --- |
| コース移動 | 矢印キー | 十字ボタン |
| ミート打ち / 投球 | Z | 黄ボタン |
| 強振 / 球種切替 | X / ←→ | 赤ボタン |
| 決定 / 見送り | Enter | - |
| 戻る | Esc | メニュー |

## ローカルで動かす

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## テスト

スマホ守備では、指を離すと操作中の野手が自動で追球し、十字キーで手動移動もできます。捕球後はプレー全体をスローにして、塁ボタンの1タップで送球。黄色はおすすめの送球先です。球審音声・守備案内中はBGMを下げ、チャレンジのホームランにも音声を追加しています。

```sh
node --test tests/
```

## GitHub Pages

`main` ブランチへの push で `.github/workflows/pages.yml` が自動デプロイします。
初回のみ、リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。
